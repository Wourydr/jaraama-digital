# Jaraama Digital

Site vitrine de **Jaraama Digital** — création de sites web rapides, boutiques e-commerce et automatisations à Dakar, Sénégal.

## Aperçu du contenu

- **Accueil** : présentation de l'offre, délai de livraison (7 jours), paiements Wave / Orange Money / virement.
- **À propos** : présentation de Woury et des atouts locaux et techniques.
- **Services & Tarifs** : site vitrine, e-commerce, automatisation sur-mesure et maintenance mensuelle.
- **Processus** : parcours client en 4 étapes.
- **Contact** : accès direct par WhatsApp et Email.

## Utilisation locale

Ouvrir directement `index.html` dans un navigateur ou lancer un serveur local :

```bash
python -m http.server 8080
```
